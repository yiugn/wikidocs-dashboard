# 통합 임상 분류 도구

검토일: 2026-10-27. 환자 정보를 저장·전송하지 않는 순수 JavaScript 규칙 기반 도구입니다.

## 파일

- static/vaccination-dashboard/clinical-engine.js: 입력 검증과 결정론적 분류. 브라우저 및 Node에서 같은 엔진 사용.
- static/vaccination-dashboard/integrated-clinic.js: 체크박스(있음/없음/미확인), 수치 입력, 판단 근거와 원문 링크.
- tests/clinical-engine.test.cjs: 46개 소프트웨어 경계값·회귀 테스트. 실행: node --test tests/clinical-engine.test.cjs

## 근거

- 고혈압: KSH 2026 제6판 수정본, 표 10·11·13, 권고 8–18 및 유지·추적.
- 당뇨병: KDA 2025 제9판, 진단·목표·유형·약물치료.
- 지질: KSLA 2026, 표 2-3~6·본문·당뇨병 장.
- 골다공증: KSBMR 2023 폐경 후 치료전략, 대한폐경학회 2024 공개 지침. 2026 비공개 전문은 미검토.

## 안전 경계

없음과 미확인을 구분합니다. 미입력 숫자는 0이 아닙니다. 위험인자의 불확실성은 개수 범위와 추가 확인 항목으로 표시합니다.
확진·약물 용량 처방을 대신하지 않습니다. 치료 중 정상화된 검사값을 완치로 처리하지 않습니다.
임신·소아·응급 증상은 일반 외래 알고리즘과 분리합니다. FRAX는 임의 공식을 구현하지 않고 공식 한국 산출값을 선택적으로 입력받습니다.
남성·폐경 전 여성에게 폐경 후 여성의 약제 순서를 자동 적용하지 않습니다. 유지투석·데노수맙·저혈당 등은 별도 안전 분기입니다.
테스트 통과는 소프트웨어 회귀검증이며, 외부 임상 타당성 검증이나 의료기기 인증을 뜻하지 않습니다. 실제 사용 전 의료진의 원문·허가·급여 확인이 필요합니다.
